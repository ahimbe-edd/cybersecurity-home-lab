# Cybersecurity Home Lab

A hands-on virtualized lab environment built to simulate enterprise security operations, Active Directory administration, and penetration testing.

## Tools & technologies
VirtualBox · Windows Server 2022 · Windows 11 · Kali Linux · Metasploitable 2 · Splunk Enterprise · Active Directory

## Lab phases
| Phase | Topic |
|-------|-------|
| 1 | Environment setup & Active Directory deployment |
| 2 | Active Directory hardening (GPO, audit policies) |
| 3 | Network segmentation (192.168.56.0/24 host-only) |
| 4 | Attack simulation & penetration testing |
